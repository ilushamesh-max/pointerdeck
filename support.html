PointerDeck support

Get the connection back.

PointerDeck needs the free PointerDeck Receiver, the same local network, Local Network permission, and Mac Accessibility permission.

Watch the 42-second animated walkthrough for an overview of pairing, gestures, and trusted-device reconnection.

Quick setup check

Starting from scratch? Read How to use your iPhone or iPad as a mouse for Mac for the complete setup and gesture guide.

  1. Download PointerDeck Receiver 1.0, install it in Applications, and keep it open.
  2. Make sure the iPhone/iPad and Mac are on the same private local network, not a guest/client-isolated network.
  3. On iPhone/iPad, open Settings > Privacy & Security > Local Network and allow PointerDeck.
  4. On Mac, open System Settings > Privacy & Security > Accessibility and allow the exact PointerDeck Receiver in Applications.
  5. Create an 8–12 digit PIN on the Mac using at least five different digits. Repeated and sequential patterns are rejected. Choose Add Device, then pair while the window is open for up to two minutes.

The Mac does not appear

  • Confirm both devices are on the same local network.
  • Public, corporate, hotel, and guest Wi-Fi often isolates devices; try a private network you control.
  • Check Local Network permission on both devices.
  • Quit duplicate or older receiver copies, then reopen PointerDeck Receiver from Applications.
  • Do not forward router ports. PointerDeck is not designed for public-internet access.

The pointer does not move

If PointerDeck says Connected but the pointer does not respond, verify Accessibility permission for the exact receiver installed in Applications. macOS can treat a rebuilt, moved, or differently signed copy as a different app.

The saved Mac no longer reconnects

Automatic reconnection works when both apps are open and reachable. If the saved credential was revoked or replaced, use the option to forget the saved Mac in PointerDeck on iPhone/iPad, reopen Add Device on Mac, and enter the current PIN.

The Mac rejects a new PIN

Use 8–12 digits with at least five different digits. Avoid repeated blocks and ascending or descending sequences. The Mac rejects weak patterns before saving them.

Scrolling feels reversed

Open Trackpad Settings and choose Natural or Reversed scrolling. The Mac receiver’s incoming-scroll setting should not accidentally invert the controller twice; use the combination that produces the expected direction.
